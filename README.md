# C# 공부 정리 (기초부터 심화까지)

처음 프로그래밍을 배우는 대학교 1학년 수준을 기준으로, C#을 기초 문법부터 최신 기능까지 정리한 학습 노트입니다. 각 장마다 개념 설명, 예제 코드, 연습문제가 있고, 각 부의 끝에는 배운 내용을 묶어 보는 미니 프로젝트가 있습니다.

- 기준 버전: **C# 15 / .NET 11** (2026년 11월)
- 예제는 최상위 문(top-level statements) 방식입니다. `dotnet new console`로 만든 프로젝트의 `Program.cs`에 그대로 붙여 넣어 실행할 수 있습니다.

## 공부 순서 추천

1. **1부 → 2부**는 순서대로, 건너뛰지 않고 봅니다. 모든 내용의 바탕입니다.
2. **3부**는 15~18장(제네릭, 컬렉션, 람다, LINQ)을 먼저 확실히 합니다.
3. **4부**는 23장(비동기)과 30장(의존성 주입)이 필수이고, 나머지는 개념만 잡아도 됩니다.
4. **5부**는 교재·인터넷 자료와 문법이 다를 때 찾아보는 용도로 씁니다.
